# 硬炭 XRD 自动分析工具（网页版 + 可打包 EXE）

这个项目提供一个可直接使用的 **Streamlit 网页应用**，用于处理硬炭 XRD 数据并自动计算：

- `d002`
- `Lc`（沿 c 轴晶粒尺寸）
- `La`（沿 a 轴晶粒尺寸）

并给出 (002)/(100) 峰位与 FWHM。

## 1. 快速启动（网页版）

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开后，上传数据文件即可分析，程序会自动识别 2θ 与强度列。

支持格式：`.csv` / `.txt` / `.dat` / `.xlsx` / `.xls`。

列识别策略：
- 优先按列名识别（如 `2Theta`/`2θ`/`角度` 与 `Intensity`/`强度`/`Counts`）
- 若无表头则自动从数值列中推断

## 2. 计算方法


## 2.1 分析模式（新增）

- **区间拖拽 + 键入并存**：手动模式下可通过滑块拖拽区间，也可精确键入左右边界。
- **单文件独立调参**：在批量上传基础上，可对任意单文件覆盖全局参数并独立分析。
- **X轴范围统一控制**：单个X范围同时用于数据分析与图像显示，并支持直接键入。
- **拟合评价机制**：新增 R²、RMSE 与 Fit Grade（A/B/C/D）用于质量判断。
- **20–32°双峰分解**：可对20多度双峰进行双 pseudo-Voigt 分峰，输出两个峰位、d间距、积分面积与积分面积比例。
- **背景原理教程内置**：侧边栏可随时展开查看各背景模式原理与建议调参流程。
- **一键快速自动分析**：自动在默认窗口内寻找峰顶，并生成更聚焦的拟合区间。
- **手动高级分析**：可手动设置 (002)/(100) 峰拟合区间，更接近 Origin 常用手工流程。
- **支持多文件上传与批量汇总**：每个文件独立标签页查看，最终提供总表下载。
- **平滑模式**：
  - `savgol`：Savitzky-Golay
  - `moving_average`：移动平均
  - `none`：不平滑
- **背景处理模式**：
  - `percentile`：分位数扣背景（默认）
  - `rolling_min`：滚动最小值背景
  - `poly`：多项式背景
  - `asls`：AsLS 背景
  - `none`：不扣背景

- Bragg 定律：
  - `d002 = λ / (2 sin θ002)`
- Scherrer 方程：
  - `Lc = Kc λ / (β002 cos θ002)`
  - `La = Ka λ / (β100 cos θ100)`

说明：
- `β` 为峰 FWHM（弧度），可扣除仪器展宽：`β = sqrt(β_meas^2 - β_inst^2)`。
- 默认峰拟合区间：
  - (002): 20–32°
  - (100): 38–52°
- 峰形采用 pseudo-Voigt + 一次线性背景。

## 3. 打包为 Windows EXE

推荐使用 PyInstaller：

```bash
pip install pyinstaller
pyinstaller --onefile --name hardcarbon_xrd app.py
```

> 说明：Streamlit 本质是本地网页服务，打包后运行 EXE 会启动本地服务并自动在浏览器打开页面。

若你希望“纯桌面窗口”形式，也可后续改为 PySide6/Tkinter 前端，核心计算模块可继续复用 `xrd_analysis.py`。

## 4. 运行测试

```bash
pytest -q
```

## 5. 数据建议

- 2θ 范围建议覆盖 10–70°。
- 建议步长 ≤ 0.05°。
- 如果噪声较高，开启平滑可提高拟合稳定性。
